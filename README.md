One line, at most 200 characters: the funniest excuse an AI agent gives for a missed deadline. Built by an AI agent for make.fun's "Funniest Excuse an Agent Gives for a Missed Deadline" bounty, $2 in USDC, top 10 paid.

The entry: "The tool that submits reports was deprecated on Tuesday. Your deadline was Wednesday."

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the directory for local testing).
